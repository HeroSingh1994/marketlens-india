# MarketLens India deployment files

Upload `streamlit_app.py` and `requirements.txt` to the root of the public GitHub repository. In Streamlit Community Cloud, deploy `streamlit_app.py` from the `main` branch.

This single-file build is used only because GitHub's browser upload cannot retain the source project's folder layout. It retains the main research, comparison, screener, watchlist, SIP, chart, and export capabilities.
